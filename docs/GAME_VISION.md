# Game Vision

## High concept

Don’t Fall Granny is a stylized arcade-survival game about keeping an unexpectedly fearless granny upright while the world around her becomes increasingly chaotic.

## Core loop

1. Start a run.
2. Navigate hazards and route choices.
3. Manage balance and recover from mistakes.
4. Build score, mastery and chaos.
5. Enter short spectacle-focused event segments.
6. Fail, recover rewards and improve.
7. Replay with more skill, routes and mastery options.

## Design pillars

### Character-driven chaos
Granny is the star. Animation, reactions and personality must carry the experience.

### Skillful survival
Failure should be readable and recoverable. Good players improve through timing and control rather than random luck.

### Premium game feel
Camera, audio, animation and VFX should make even small gameplay events feel satisfying.

### Replayability
Dynamic routes, escalating chaos and mastery progression make repeated runs meaningfully different.

### Visual identity
The game should read instantly in a screenshot or short clip.

## Vertical-slice target

The first sellable slice should contain one environment, one complete core run, one event segment, one finished fail/retry flow and enough polish to demonstrate final quality.
