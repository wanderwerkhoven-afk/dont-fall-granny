# Premium Mobile UX Flow

## Front end

### Home
Primary visual: Granny.
Primary action: Play.
Secondary actions: Loadout, Settings.

Do not make the shop the dominant screen.

### Loadout
One focused customization screen for:
- outfit;
- gadget;
- preview.

Return to Home or start directly from the selected loadout.

## Run flow

1. Run start
2. Gameplay HUD
3. Optional Recovery Prompt
4. Fall impact beat
5. Rescue Card
6. Final Game Over
7. Replay or Home

## HUD budget

Persistent:
- score / distance;
- balance / tension state;
- coins.

Contextual only:
- special-mode timer;
- recovery action;
- temporary objective.

Do not show mastery, inventory, shop and mission detail simultaneously during normal running.

## Recovery

Recovery is an urgent microinteraction:
- gameplay remains visible;
- nonessential HUD recedes;
- one large Recover action;
- jumping disabled;
- reduced forward speed;
- short timer;
- no modal menu feeling.

## Rescue

Rescue is a post-fall decision:
- show Granny state first;
- perimeter countdown around card;
- Rescue / Continue is the primary action;
- Home / Accept Game Over is secondary;
- card appears only after the impact beat.

## Final Game Over

Information order:
1. Result
2. Reward / progression summary
3. Replay
4. Home

Replay should be reachable in one tap.
