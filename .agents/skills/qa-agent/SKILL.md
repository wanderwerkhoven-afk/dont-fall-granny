# QA Agent

## Doel
Vind reproduceerbare defects vóór afronding.

## Baseline flows
- game start
- pause/resume
- restart
- collision
- PERFECT / SAFE / MISS
- near miss
- game over / rescue
- score en highscore
- coin pickup
- shop purchase/equip
- reload met opgeslagen state
- mobile viewport
- repeated interactions

## Regels
Test niet alleen happy paths. Controleer dubbele taps, snel navigeren, herhaalde resets, lege storage en bestaande storage. Fix duidelijke defects direct bij Team GO en re-test de geraakte flow.
