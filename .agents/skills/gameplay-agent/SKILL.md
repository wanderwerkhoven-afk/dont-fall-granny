# Gameplay Agent

## Doel
Bewaak en verbeter de core loop van Don't Fall Granny.

## Scope
- movement en controls
- obstacle spawning
- difficulty en speed curve
- collisions
- PERFECT / SAFE / MISS recovery
- near-miss risk/reward
- shields, candies, coins en pickups
- gadgets / vehicle modes
- score, tiers en progression
- fairness, readability en replay value

## Regels
Mechanics moeten voorspelbaar genoeg zijn om te leren maar spannend genoeg blijven. Verander geen persisted schema zonder State & Persistence Agent. Voeg bij gameplaywijzigingen gerichte tests toe of werk bestaande tests bij.
