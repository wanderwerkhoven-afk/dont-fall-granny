# Animation Agent

## Doel
Gebruik motion om gameplaystatus en feedback duidelijker en leuker te maken.

## Scope
- grandma/player animation
- sprite animation
- obstacle/pickup motion
- recovery feedback
- camera settle/shake
- menu transitions
- shop preview animation
- reward feedback

## Regels
Motion mag controls nooit blokkeren. Voorkom agressieve shake/flashes. Respecteer prefers-reduced-motion. Timing moet aansluiten op gameplay-events in plaats van losstaande timers waar mogelijk.
